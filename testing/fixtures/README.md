# Vision fixtures

Place consented, locally captured PNG frames here using this naming scheme:

- `landscape-clear-<width>x<height>.png`
- `landscape-obscured-cue-<width>x<height>.png`
- `portrait-windowed-<width>x<height>.png`

For each image add a same-name `.json` file containing table bounds, pockets, ball centers/radii, cue-ball identity, and cue direction (or `null`). No frames are bundled because none were provided and the project does not persist captures by default.
